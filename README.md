# 🏋️ Fitlog

**Brogram | The Simple 30 WOs Training Plan**

A simple workout tracker built with React. Follow a 30-workout training plan and see your progress at a glance.

## 📖 About

Fitlog is built around the 30-workout plan. The goal is to keep training simple: open the app, see what's next, do the workout, and track how far you've come.

This project is based on the open-source [Brogram](https://github.com/jamezmca/2_brogram) workout planner by Smoljames. I extended it with a progress bar and a redesigned UI (see [Acknowledgements](#-acknowledgements)).

## ✨ Features

- Follow a structured 30-workout training plan
- Progress bar to visualize your progress through the plan
- Redesigned, clean and simple interface

## 🛠️ Tech Stack

- [React 19](https://react.dev/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/buseuygun/2_Fitlog.git

# Go into the project folder
cd 2_Fitlog

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open the local URL shown in your terminal (usually `http://localhost:5173`).
